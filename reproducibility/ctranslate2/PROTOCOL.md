# Prospective held-out engine test: CTranslate2

Frozen on the author's machine, before generating any target outputs or reading the target's result-assembly code in this study. The original test concerned agreement of each reported selected pair with the same emission. CTranslate2 was not an engine or formatter in the design panels. Its released Python/C++ generation interface exposes selected IDs, pieces, scores and optional full-vocabulary values. This is a native engine-client boundary, not a new HTTP server. One target only. Model and prompts are selected on availability and transport coverage, not on target results.

## Population and paths

Use released CTranslate2 4.9.0 (arm64 CPU float32, beam_size=1, one worker and one thread where supported), pinned SmolLM2-135M-Instruct revision 12fd25f77366fa6b3b4b768ec3050bf629380bac converted from the existing verified checkpoint. Use plain prompts, encode without added specials; no penalties, custom stops, logit bias, or forced tokens; allow ordinary EOS and document the endpoint's EOS inclusion rather than dropping rows to obtain agreement. Primary generation limit 12 positions. Treat tokenizer/model conversion or missing platform dependency as a setup failure: repair before measuring, keep an attempt log. No substitution of an engine after results.

Six literal prompts, in order (one string per line):

1. The book on the table was
2. In a quiet garden, the
3. 0, 1, 1, 2, 3,
4. She said: "I think
5. Le café est
6. 春天来了，

For each run both a neutral non-greedy regime (temperature 1, top-k disabled, top-p 1) and a sampling stress (temperature 0.7, top-k 5, top-p 1). Two seeds per prompt, 1701 and 2701, for 24 planned calls per path. A supplementary greedy control at temperature 1, top-k 1, seed 1701 on all six. Reset seed before each call; matching seeds across calls are not evidence of a shared event. Use two public paths: streaming native generate_tokens with return_log_prob and, separately, generate_batch with step callback, return_scores and return_logits_vocab; no prompt echo for final sequences. Use single-prompt batches. If a particular combination is unsupported, record it, exercise supported subsets, and keep those counts separate. A second presentation of a captured event with optional fields suppressed is a formatter test only when the actual engine assembler can be invoked on that event. Otherwise label this axis unavailable. Do not substitute a synthetic serializer.

## Verdicts fixed before acquisition

For each path preserve the sampled IDs, generation steps, pieces, emitted log probabilities and response as actually exposed. For batch store callback rows and final sequence IDs in draw order and all returned vocabulary vectors where supported. For numeric grading also evaluate original engine forward_batch on the exact realized prefix; retain full original vectors locally for regrading. Identify from released source after freeze whether callback ID comes from the native selected action, where probabilities come from, whether callback/result and consumer share fields, when EOS is counted, and whether each public property is logits, raw normalized scores, or a transformed sampling distribution. Use the same-event vector when available; compare an independent exact-prefix forward as a secondary reference, never as a separate random draw. If stronger hooks are practical preserve the ID fed into the next decoder step. For streams a forwarded callback or emitted ID alone is not an independent ID oracle. Distinguish same-event comparisons, independent prefix forward, decoder prefix witness, shared lineage, and abstentions.

Conventional checks: reported piece(s) must decode to the same visible bytes/text as the engine's returned token sequence under the pinned tokenizer, row/step counts must agree with documented stop behavior, and token labels map to their reported IDs. Use raw byte-level vocabulary map for the bytes check; flag unavailable where the interface supplies no literal byte field. Test numerical association at the native ID; for batch also require correct reported surface, test whether an aggregate follows the source-declared convention only when defined. Do not assume candidates include the chosen item, or that optional vocabulary output is normalized based only on its name. Count top-1 vs off-first, rank>5 when calculable, row-level and complete-draw outcomes separately. A candidate hidden defect needs conventional checks passing in the same draw plus a contradiction with an independently established contract and/or same-event witness. Offsets, unexposed fields, genuine alternative score stages and unsupported modes are not faults. For independent float32 compare absolute error <= 0.0002 + 0.00002 * abs(reference); inspect first discrepancy using exact same-step vector and source lineage before attributing a defect. In stress mode report raw vs temperature/top-k normalized distributions separately; a disagreement with one admissible convention alone cannot establish misattribution. For an ambiguous contract report ambiguity instead of choosing a favorable oracle. When a discrepancy arises check the original release path unchanged and a focused confirmation; label subsequent diagnostics and any prior reports.

Grade a copy-only score substitution control by replacing one off-first selected score with the same-step top-one score while leaving IDs/pieces/counts unchanged. The test should reject the numeric error and conventional checks should agree. Keep this control separate from real defects. Preserve all attempts/results, including zero errors or an ineffective oracle. Only claim novelty after comparing post-hoc against public reports, and only claim upstream confirmation if obtained. No external messages or submissions.
