# Retrospective comparison on frozen events

This analysis reuses releases, prompts, settings, failures and control outputs already examined in earlier studies. Its rule is recorded before the comparative tallies. It is not a prospective discovery or an estimate of defect prevalence. No new generation, training, synthetic failures or upstream changes enter the comparison.

Panels: all 64 paired MLX IFEval original/corrected responses; all 12 llama.cpp prompts at positive widths one and five reported separately (primary width five), zero width for availability only; the preselected multilingual mistral.rs panel (84 per transport with its preselected 14 per transport path-witness subset); the 60 CTranslate2 singleton calls, all fixed joint/split/singleton coverage confirmations and the existing one-row copied score substitution. Use existing control pairs, shared references and excluded/ambiguous rows explicitly. Never multiply effective draws by counting formats, shared callbacks or width arms as independent.

Inputs to each check are limited by access. At response level compare (when exposed) rendered text or re-rendered IDs under the actual stop convention, row count vs recorded token count. At row/item level use coverage (including strict one vocabulary row per item when requested), canonical bytes/labels where unambiguous, or map the visible text to IDs where specified. At producer access compare ID and score against the same draw; record numerical stage, tolerance and equality of score with a different ID separately. A full-prefix calculation conditional on previous exposed IDs can test a numerical value but is not an independent witness of the chosen ID. Distinguish unique reconstructed paths, next-decoder ID readings, and shared-origin final/stream arrays. Keep literal renderer and post-hoc stop-aware variants labeled. Do not infer a location from a response alarm. Do not turn an unavailable or empty field into zero or assume an inferred ID when text has ambiguous segmentation.

Report alarms and false alarms on comparable negative controls, whether the exact affected field and position(s) can be localized (including wrong claims on controls, missed errors and abstentions where computable), and the number of correct/wrong/abstained recovered requested values. Separate ID, selected scalar, full pair, bytes, and full row, including restoration from final results versus availability to a live callback. In-scope targets and denominators must be explicit; no pooled metric across non-equivalent tasks. A comparison needs the same frozen unit, same field, and an independent label or declared shared lineage. Matching on determinate units is conditional, never success for abstentions. Untested capabilities use an explicit unavailable mark. Existing injection belongs in its own control.

Use the same executable comparison for cross-engine claims on labeled slot values, with adapters that provide publicly observed values and correctly typed references. Preserve reported baselines that succeed, correctly abstain or equal the stronger oracle. Do not describe a baseline inspired by MURPHY as execution of its full suite. List actual access requirements with results. Archive the pre-revision review bundle and distribute only reviewed numerical projections, code and provenance sufficient for offline verification.
