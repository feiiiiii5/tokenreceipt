# Additional score-consistency comparison

After the initial exact-lookup comparison and before counting cutoff results, we added the one-sided bound already used for MLX archival ranking and repeat validation in the frozen manuscript. The complete genuine top set must be from the same score vector and stage as the selected scalar. If the proposed selected ID is listed, check the exact listed score. If it is absent, any true score is at most the smallest listed value: a strictly larger reported scalar proves a numerical error, even without an exact replacement value. Otherwise abstain. An unknown or unaligned ID is an abstention. The canonical-ID variant is conditional on segmentation; grade wrong alarms against both archived source and corrected responses. Keep all existing panels, exact recovery decisions and tie conventions. This is a retrospective elaboration; the counts were not part of the original acquisition design. For byte-label heuristics report both an entire replacement-byte row and a row containing the replacement sequence, and grade them against the same unique-path subset.
