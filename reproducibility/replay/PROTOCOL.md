# Checking replayed scores against an archived top-five list

The paper's existing 80-prompt replay shows that matching visible output can admit a different score sequence. The summaries and four original failures are already known. Before computing any new filter outcomes, fix the following post-hoc reanalysis and a disjoint prospective test. The intended decision is whether to use a candidate-free repeat to rank four original answers, with earliest draw breaking ties. We do not tune the rule or add cases based on the result.

* Baseline requires identical transcript (including null), finish reason, and equal row counts and completion-token usage across both responses. A second baseline also requires equal reported cached prompt-token counts.
* Proposed filter retains the first baseline and checks every repeat ID and score against the original top five. A listed ID must have the exact archived score; an unlisted ID's score must be at most the smallest of the five. Tied cutoffs pass. This tests compatibility under the checked MLX raw score convention; unlisted values and alternate tokenizations can remain indistinguishable. Compare a fourth arm requiring both this test and cache-count equality. Native observations may only grade outcomes, never determine acceptance.
* For each arm and each policy separately count accepted responses, accepted with wrong native ID or score sequences, accepted with wrong scores, issued four-draw rankings, incorrect rankings, and corrections of wrong original rankings. Retain exact-pair controls and detect any unjust rejection of an otherwise eligible exact pair by the proposed compatibility check. No pooling of settings or treating them as independent replications.
* Historical panel: original 80 fresh IFEval keys, same and shifted interleaved seeds, and the four existing order/cache settings. Prospective panel: from IFEval exclude the frozen 64 localization, 40 decoding, 80 requery, and 36 long-response panel keys. Take the first 64 remaining keys by SHA256 of `replay-evidence-v1/` plus the decimal key. Four draws per key, original collection payload as in the earlier 80-prompt study, seeds `73803+10*key+draw`, cap 24, temperature 0.8. Fix input and method before acquisition. Collect original top-five response and same-emission witness in forward order. Repeat candidate-free from separate stock processes using original seed in forward/default (positive control), reverse/default (order stress), forward/zero cache (cache stress). Keep all captures in the local study. No new shifted seeds on the confirmation. Report false accepts and abstentions even if the new rule fails; with zero baseline failures an arm provides no discrimination evidence. The only new sampling unit is the 64 disjoint prompts on the same release/checkpoint. No new model training or upstream publication.
