Title
When a Language Model Server Reports a Different Token

Authors
Yufeiyang Chen

Abstract
Applications route queries, grade responses, and update policies using the probability attached to each generated token. Does the reported probability belong to the token actually sampled? Toggling candidate-list inclusion on the same sampling event exposes an attribution substitution in eight consecutive releases of MLX-LM (0.30.6-0.32.2): requesting alternatives overwrites the outer selected entry with the first candidate while emitting intact generated text. Formalizing five contract invariants (I1-I5) in an open audit suite separates substitution in MLX-LM (528/1,488 IFEval positions and Qwen2.5-3B) from row omission in llama.cpp (3/280), UTF-8 byte corruption in mistral.rs (708 FLORES-200 positions), and cross-row batch callback leakage in CTranslate2 4.9.0 (24/24 equal-length steps). A hardened patch restores all 11 checks and passes 128 live SmolLM2 and Qwen2.5-3B positions. Downstream on Qwen2.5-3B ARC-Challenge (N=250), wire inflation (+0.194 nats) lowers aggregate ECE (0.125 to 0.032) yet flips 117/250 routing decisions, raising wrong-answer false acceptance from 27.1% to 76.3% (p<1e-6), while breaking score-span matching in DeepEval G-Eval (6/94 pass flips) and cutting SST-2 learning accuracy by 1.90 percentage points across 128 seeds.
